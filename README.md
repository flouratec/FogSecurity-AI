# FogSecurity-AI

FogSecurity-AI is an AI-driven fog computing security framework designed to ensure:

- Secure node authentication (ANT)
- Seamless session mobility (MTP)
- AI-based adaptive trust evaluation
- High availability and low latency fog services

## Research Goal
This project proposes an integrated fog security architecture combining authentication, availability, and AI-driven behavioral monitoring.
